# Tasks 統合メモ

## 画面とAPI

- `/tasks`: 1行1タスクのノート一覧、チェックによる完了、検索、ビュー切り替え、作成・編集
- `/api/v1/tasks`: 一覧（GET）、作成（POST）、更新（PATCH）、削除（DELETE）

タスク画面は共通のPages FunctionsとD1、共通HttpOnlyセッションを利用します。別サイトや専用ログインは作成しません。

一覧は未完了・完了・すべての3ビューを持ちます。入力欄では複数行をまとめて追加でき、空行は無視します。各行のタイトルはその場で編集でき、詳細編集から説明、期限、優先度、ステータスを変更できます。

## データ

`0017_tasks_initial.sql`で`task_items`を作成します。`0023_tasks_notebook_order.sql`でノート表示順の`sort_order`を追加します。データは共有owner名前空間の`owner_id = 'owner'`で管理し、タイトル、メモ、期限、ステータス、優先度、作成・更新日時、完了日時を保存します。

既存タスクは作成日時順で初期化し、新規タスクは末尾に追加します。一覧APIはこの順序で返します。完了への変更時は完了日時を記録し、未完了へ戻すと完了日時を解除します。
