# Tasks 統合メモ

## 画面とAPI

- `/tasks`: 1行1タスクのノート一覧、制限記録、解除通知
- `/api/v1/tasks`: タスクの一覧・作成・更新・削除
- `/api/v1/tasks/restrictions`: 制限記録の一覧・作成・更新・削除

タスク画面は共通のPages FunctionsとD1、共通HttpOnlyセッションを利用します。別サイトや専用ログインは作成しません。

一覧は未完了・完了・すべての3ビューを持ち、カテゴリでも絞り込めます。カテゴリはタスク詳細から自由入力し、未設定のタスクは「未分類」として扱います。入力欄では複数行をまとめて追加でき、空行は無視します。各行のタイトルと展開した詳細は直接編集できます。新規行の追加と既存行の更新は、鉛筆アイコンから同じUpsert処理で行います。アコーディオンの詳細は初期状態で閉じ、メモ・カテゴリ・期限・優先度・ステータスを表示します。並び順は入力順、新しい順、名前順、期限順、優先度順を切り替えられます。

## データ

`0017_tasks_initial.sql`で`task_items`を作成します。`0023_tasks_notebook_order.sql`でノート表示順の`sort_order`、`0024_tasks_category.sql`でカテゴリを追加します。データは共有owner名前空間の`owner_id = 'owner'`で管理し、タイトル、カテゴリ、メモ、期限、ステータス、優先度、作成・更新日時、完了日時を保存します。

既存タスクは作成日時順で初期化し、新規タスクは末尾に追加します。一覧APIはこの順序で返します。完了への変更時は完了日時を記録し、未完了へ戻すと完了日時を解除します。

## 制限記録と解除通知

制限タブでは記録名、実施日、期間（日・か月・年）を登録できます。期間の最終日までは制限中として扱い、その翌日を解除予定日にします。たとえば2025年12月30日に「忘年会」、期間を1年で登録すると、解除予定日は2026年12月31日です。月末やうるう日の加算は、対象月に同じ日がない場合その月の最終日に合わせます。

登録後の制限名は変更でき、記録の削除もできます。解除予定日以降にTasksを開くと、未確認の解除通知を画面上部に表示します。通知を閉じた状態は`notification_dismissed_at`に保存し、再表示しません。これはアプリ内通知のため、Tasksを開いていない間にOS通知を送る機能ではありません。制限記録は`0025_task_restrictions.sql`の`task_restrictions`に保存し、共通セッション認証済みAPIで管理します。
