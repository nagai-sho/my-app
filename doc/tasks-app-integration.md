# Tasks 統合メモ

## 画面とAPI

- `/tasks`: 個人タスクの一覧、検索、ビュー切り替え、作成・編集
- `/api/v1/tasks`: 一覧（GET）、作成（POST）、更新（PATCH）、削除（DELETE）

タスク画面は共通のPages FunctionsとD1、共通HttpOnlyセッションを利用します。別サイトや専用ログインは作成しません。

## データ

`0017_tasks_initial.sql`で`task_items`を作成します。データは共有owner名前空間の`owner_id = 'owner'`で管理し、タイトル、メモ、期限、ステータス、優先度、作成・更新日時、完了日時を保存します。

一覧は未完了を先に、期限の近い順に返します。完了への変更時は完了日時を記録し、未完了へ戻すと完了日時を解除します。
